## Abstract
AlphaEvolve, introduced in [224], is a generic evolutionary coding agent that combines the generative capabilities of LLMs with automated evaluation in an iterative evolutionary framework that proposes, tests, and refines algorithmic solutions to challenging scientific and practical problems. In this paper we showcase AlphaEvolve as a tool for autonomously discovering novel mathematical constructions and advancing our understanding of long-standing open problems.
To demonstrate its breadth, we considered a list of 67 problems spanning mathematical analysis, combinatorics, geometry, and number theory. The system rediscovered the best known solutions in most of the cases and discovered improved solutions in several. In some instances, AlphaEvolve is also able to generalize results for a finite number of input values into a formula valid for all input values. Furthermore, we are able to combine this methodology with Deep Think [149] and AlphaProof [148] in a broader framework where the additional proof-assistants and reasoning systems provide automated proof generation and further mathematical insights.
These results demonstrate that large language model-guided evolutionary search can autonomously discover mathematical constructions that complement human intuition, at times matching or even improving the best known results, highlighting the potential for significant new ways of interaction between mathematicians and AI systems. We present AlphaEvolve as a powerful tool for mathematical discovery, capable of exploring vast search spaces to solve complex optimization problems at scale, often with significantly reduced requirements on preparation and computation time.

## Notation and conventions
- "Problem 6.k" = the k-th problem of Section 6 (44 subsections, 65 numbered problems 6.1-6.65 plus the Section 6.44 bonus experiments; the abstract says 67 problems). C_{6.k} denotes the constant/quantity of Problem 6.k (p. 9-10). "SotA"/"best known" is the value in the literature at the time; "→" below means previous bound → AlphaEvolve bound.
- Notation X ≲ Y: |X| ≤ C·Y for a constant C independent of the parameters (p. 9).
- **Search mode** (p. 3, 5): each evolved program is a search heuristic given a fixed time budget (e.g. 100 seconds) and shown the best construction so far; its score is the score of the best object it finds. **Generalizer mode** (p. 4): AlphaEvolve writes a program that solves the problem for any input size n, evaluated on a range of n values. Evaluator = deterministic user code giving a numerical score; total CPU hours ∝ number of LLM calls since each evaluator has a fixed time budget (p. 5).
- Lattice relevance: no knot, polymer, ropelength or lattice-walk problem occurs in the paper. The only lattice-point problems are Problems 6.59 and 6.60 (point sets in grids [n]², [n]³) and Problem 6.56 (Z² points/rational lines).

**Problem 6.1 (p. 11-13): Kakeya and Nikodym sets over finite fields.** For d ≥ 1 and q a prime power, a Kakeya set in F_q^d contains a line in every direction; a Nikodym set N is such that every point x of F_q^d lies on a line contained in N ∪ {x}. C^K_{6.1}(d,q), C^N_{6.1}(d,q) = least sizes. Known (as printed, p. 11-12): C^N ≥ C^K − 2q^{d−1} − …, so Nikodym ≳ Kakeya − O(q^{d−1}); C^K(1,q) = C^N(1,q) = q; C^K(2,q) = q(q+1)/2 + (q−1)/2 for q odd, q(q+1)/2 for q even [205, 32]; C^N(2,q) ≥ q² − q^{3/2} − 1 + (4/3?)… (the lower bound from blocking sets [276], a fractional-part correction term is garbled, ⚠), sharp up to O(q log q) when q is a perfect square [31]; C^K(d,q) = q^d/2^{d−1} + O(q^{d−1}) [49]; conjecture C^N(d,q) = q^d − o(q^d) [205]; Cartesian-product inequalities C(d1+d2,q) ≤ C(d1,q)C(d2,q); for q a perfect square upper bound for Nikodym via [31]. *AlphaEvolve results (generalizer mode, p. 12-13):* new Kakeya constructions with lower-order improvements for primes p ≡ 1 mod 4: d = 3: C^K(3,p) ≤ (1/4)p³ + (7/8)p² − 1/8 (previous (1/4)p³ + (7/8)p² + O(p) [49]) via an explicit set built from quadratic residues S with g = (p−1)/4 (image-checked); d = 4: C^K(4,p) ≤ (1/8)p⁴ + (19/32)p³ + (11/16)p² + O(p^{3/2}) (error involves elliptic curves, Deep Think proof checked by hand); d = 5: size (1/16)p⁵ + (47/128)p⁴ + (177/256)p³ + O(p^{5/2}) (verified by hand). Leading two coefficients match [49]; lower-order terms refined. d = 3 proof formalised in Lean via AlphaProof (the only fully formalised case). Nikodym: AlphaEvolve's 3-D attempt (high-degree surfaces) was simplified by hand to give C^N(d,q) ≤ q^d − (((d−2)/log 2) + 1 + o(1)) q^{d−1} log q for fixed d ≥ 3 (human-completed, to appear in Tao [281]). With the hint that q² − q^{3/2} + O(q log q) is achievable for q = p² (d = 2) AlphaEvolve immediately found size q² − c q^{3/2}, then constructions of size q² − q^{3/2} + O(q log q); without the hint only q² − O(q log q). It also reproduced the construction of [276] after "a few hundred iterations".

**Problem 6.9 (p. 18–19) — Kakeya needle problem.** Let n ≥ 2. C^T_{6.9}(n) := minimal area |⋃_{j=1}^n T_j| of a union of triangles T_j with vertices (x_j,0), (x_j+1/n,0), (x_j+j/n,1), for some reals x_1,…,x_n. C^P_{6.9}(n) := the same for parallelograms P_j with vertices (x_j,0), (x_j+1/n,0), (x_j+j/n,1), (x_j+(j+1)/n,0). Score: S^T_{6.9}(n) := Σ_i |T_i| / ( (Σ_i Σ_j |T_i ∩ T_j|)^{1/2} · |⋃_i T_i|^{1/2} ), and S^P_{6.9}(n) analogously. Establish upper and lower bounds on C^T, C^P, S^T, S^P as strong as possible. *Background (paper):* Besicovitch's observation → C^T, C^P → 0. Known: 1/log n ≲ C^T(n) ≤ C^P(n) ≲ 1/log n, lower bound due to Córdoba [78], upper bound due to Keich [178]. From Σ_i |T_i| = ½ and Σ_i Σ_j |T_i ∩ T_j| ≍ log n: C^T(n) ≳ 1/(S^T(n)² log n), similarly for C^P; so Córdoba's lower bound follows from the trivial Cauchy–Schwarz bound S^T, S^P ≤ 1. Keich's construction shows 1 ≲ S^T(n), S^P(n). *AlphaEvolve (search mode, p. 19–20, Figs 5–6):* Fig. 5 (p. 20): optimising the total union area, AE's constructions have smaller union area than Keich's for both triangles and parallelograms for n up to 128 (found within 5–10 evolution steps, ≈1–2 h wall clock). Fig. 6 (p. 20): optimising the score S^T. The text (p. 20) says this "results in improved performance with respect to Keich's construction", but as rendered, the AE curves in both panels of Fig. 6 lie *above* Keich's union area and *below* Keich's S^T score at n = 128 (≈0.24 vs ≈0.12 area; ≈0.43 vs ≈0.81 score). ⚠ Text and figure disagree; recorded as printed. *Generalizer mode (p. 19):* AE was asked for a program giving x_1…x_n for any n, scored on a mix of sizes. Early programs were uniform-mesh-plus-perturbation and fell short of Keich's sets for large n; a prompt hint suggesting Keich's bitwise construction (x_i := Σ_{j=1}^{k} ((1−j)/k) ε_j 2^{−j} for n = 2^k, a_i = i/n = Σ_j ε_j 2^{−j}) led to programs for arbitrary n with jumps in performance near powers of 2 (Fig. 9 top); a prompt asking to avoid this produced programs with mitigated jumps (Fig. 9 bottom). Fig. 7 (p. 21): parallelogram and Fig. 8 (p. 21): triangle constructions for n = 16, 32, 64, Keich (top) vs AE (bottom). Programs are in the Repository of Problems.

**Problem 6.17 (p. 28–29) — Young's convolution inequality.** Let 1 ≤ p, q, r ≤ ∞ with 1/r + 1 = 1/p + 1/q. C_{6.17}(p,q,r) := sup over non-zero test functions f, g of Q_{6.17}(f,g) := ‖f * g‖_r / (‖f‖_p ‖g‖_q). What is C_{6.17}(p,q,r)? *Known (paper, [20]):* Q_{6.17} is extremised when f, g are Gaussians e^{−αx²}, e^{−βx²} with α/β = √(q/p), and C_{6.17}(p,q,r) = C_{6.14}(p) C_{6.14}(q) C_{6.14}(r′) (Problem 6.14). *AlphaEvolve:* with the same step-function setup as Problem 6.14, AE repeatedly followed one pattern: (1) propose two standard Gaussians f = e^{−x²}, g = e^{−x²} as a first guess; (2) introduce variations f = a e^{−bx²}, g = c e^{−dx²} with parameters a, b, c, d ∈ R; (3) add an optimisation loop (gradient descent on a, b, c, d for Q_{6.17}), which recovered the theoretically optimal coupling between the parameters. The paper notes AE almost instantly recognised the extremiser structure in most runs.

**Problem 6.18 (p. 28–29) — Hardy–Littlewood maximal inequality (one-dimensional, centred).** Let C_{6.18} be the best constant for which, for all absolutely integrable non-negative f: R → R and λ > 0,
|{x : sup_{h>0} (1/(2h)) ∫_{x−h}^{x+h} f(y) dy ≥ λ}| ≤ (C_{6.18}/λ) ∫_R f(x) dx.
What is C_{6.18}? *Known (paper):* solved completely in [212, 213]: C_{6.18} = (11 + √61)/12 = 1.5675208…. Equivalent form used by the authors: for real y_1 < ⋯ < y_n and k_1,…,k_n > 0, |⋃_{1≤i≤j≤n} [y_j − k_i − ⋯ − k_j, y_i + k_i + ⋯ + k_j]| ≤ 2 C_{6.18} (k_1 + ⋯ + k_n) (empty intervals when a > b) [212, Lemma 1]. Special cases: n = 1 gives C_{6.18} ≥ 1; k_1=⋯=k_n=1 and y_i = 3i gives 3n−1 ≤ 2C_{6.18} n, i.e. C_{6.18} ≥ 3/2 − 1/(2n) for all n. For some time C_{6.18} = 3/2 was conjectured until a tighter lower bound was found by Aldaz [4]. Gaussians and step functions are not extremisers. *AlphaEvolve:* prompted to output sequences y = {y_i}, k = {k_i} satisfying the inequality and maximising the ratio Q(y,k) between the two sides. Search mode: lower bound **C_{6.18} ≥ 1.5080** (surpassing 3/2, not reaching 1.5675), with heuristics plus random mutation and large-scale search. Generalizer mode: AE swiftly reached 3/2 with the argument above; further improvement needed more hints (e.g. from the construction in [4]), which led to configurations built from shorter repeated patterns with values up to ≈ 1.533. The authors observe no sign that the underlying LLMs knew the relation between Q(y,k) and the maximal inequality (data contamination not evident).

**Problem 6.19 (p. 29–30) — ovals problem.** For a simple closed convex curve γ parametrised by arclength s with curvature κ(s) and normalised to length 2π, let λ_0(γ) be the least eigenvalue of the Schrödinger operator H_γ = −d²/ds² + κ²(s). Let C_{6.19} be the infimum of λ_0(γ) over such curves. Obtain upper and lower bounds on C_{6.19} as strong as possible. *Background (paper):* Benguria–Loss [22] showed C_{6.19} is the smallest constant in a one-dimensional Lieb–Thirring inequality for a Schrödinger operator with two bound states, and ½ < C_{6.19} ≤ 1, with the upper bound from the unit circle and a two-parameter family of ovals collapsing to a double segment. Burchard–Thomas [50] showed C_{6.19} ≥ ¼ (optimal if curves may be open). Conjecture [22]: C_{6.19} = 1. Best lower bound: Linde [199], C_{6.19} ≥ (1 + π/(π+8))^{−2} ≈ 0.60847 (value checked numerically). *Variational form (eq. 6.6, p. 30):* I[x,φ] := ∫_0^{2π} (φ′² + |x″|² φ²) ds; λ_0 = inf { I[x,φ] : x ∈ W^{2,2}(S¹ → R^n), φ ∈ W^{1,2}(S¹), |x′| = 1, ‖φ‖²_{L²} = 1 } (Sobolev spaces W^{2,2}, W^{1,2}). *AlphaEvolve:* asked to output three real sequences on [0, 2π] (two coordinates x_1, x_2 and φ) that are spline-interpolated, with a quadrature approximation of I[x,φ] and exact derivatives (JAX, scipy; closed curves via arclength reparametrisation with 10 000 samples). In most runs AE obtained the circle (with constant φ) within a few iterations, which corresponds to the conjectured value 1. AE did not discover any ovals as additional optimal curves.

**Problem 6.20 (p. 30–31) — Sendov's conjecture.** For each n ≥ 2 let C_{6.20}(n) be the smallest constant such that for any complex polynomial f of degree n with zeros z_1,…,z_n in the unit disk and critical points w_1,…,w_{n−1}: max_{1≤k≤n} min_{1≤j≤n−1} |z_k − w_j| ≤ C_{6.20}(n). Sendov [256] conjectured C_{6.20}(n) = 1. *Known (paper):* 1 ≤ C_{6.20}(n) ≤ 2^{1/n}, upper bound from [35]. Lower bound examples: f(z) = zⁿ − 1 gives C ≥ 1; f(z) = zⁿ − z gives the slightly weaker C ≥ n^{−1/(n−1)}. The family f(z) = c(zⁿ − e^{iθ}), c ≠ 0, θ real, generalises the first example; it is conjectured in [229] to be the only extremal family. Proved for n < 6 by Meir–Sharma [211], n < 7 Brown [46], n < 8 Borcea [38] and Brown [47], n < 9 Brown–Xiang [48], and for sufficiently large n by Tao [279]; open for medium-sized n. *AlphaEvolve:* asked to choose sets of n roots in the unit disk (projected onto the disk if outside), scored by the maximum over roots of the minimal distance to the critical points (roots of p′ computed with numpy). AE rediscovered the expected maximisers p(z) = zⁿ − e^{iθ} and near-maximisers such as zⁿ − z, but found no additional maximisers.

**Problem 6.21 (p. 31) — Schmeisser's conjecture.** For each n ≥ 2 let C_{6.21}(n) be the smallest constant such that for any polynomial f of degree n ≥ 2 with zeros z_1,…,z_n in the unit disk and critical points w_1,…,w_{n−1}, and for any non-negative weights l_1,…,l_n with Σ_k l_k = 1: min_{1≤j≤n−1} |Σ_k l_k z_k − w_j| ≤ C_{6.21}(n). *Conjecture (paper):* C_{6.21}(n) = 1 [251, 252]. Clearly C_{6.21}(n) ≥ C_{6.20}(n). *AlphaEvolve:* maximised over sets of roots; for each root set many points on the convex hull (midpoints of segments and points dividing segments in ratio 2:1) were evaluated by their distances to the critical points. AE found no counterexample; all its best constructions had roots and critical points near the boundary of the disk. Fig. 14 (p. 31): a suboptimal construction obtained by forcing some roots away from the boundary (red crosses = zeros, blue dots = critical points, green plus = a point in the convex hull of the zeros at distance at least 0.83 from all critical points).

**Problem 6.22 (p. 32) — Borcea's conjecture.** For 1 ≤ p < ∞ and n ≥ 2 let C_{6.22}(p,n) be the smallest constant such that for any complex polynomial f of degree n with zeros z_1,…,z_n satisfying (1/n) Σ_i |z_i|^p ≤ 1, and every zero ζ of f, there is a critical point ξ of f with |ξ − ζ| ≤ C_{6.22}(p,n). *Background (paper):* by Hölder, C_{6.22}(p,n) is non-increasing in p and tends to C_{Sendov}(n) as p → ∞. Borcea [181, Conjecture 1] conjectured C_{6.22}(p,n) = 1 for all 1 ≤ p < ∞ and n ≥ 2 (stronger than Sendov's conjecture). Verified for (p,n) = (1,3) and (2,4) [181]. *AlphaEvolve:* focused on p = 1; proposed families zⁿ − nz and zⁿ − nz^{n−1}; attempts to push AE away from these forms (penalties for similarity to the known examples) did not produce a counterexample.

**Problem 6.23 (p. 32–33) — Smale's problem.** For n ≥ 2 let C_{6.23}(n) be the least constant such that for any polynomial f of degree n, and any z ∈ C with f′(z) ≠ 0, there is a critical point ξ of f with |(f(z) − f(ξ))/(z − ξ)| ≤ C_{6.23}(n) |f′(z)|. *Known (paper):* Smale [265]: 1 − 1/n ≤ C_{6.23}(n) ≤ 4, lower bound from p(z) = zⁿ − nz. Upper-bound improvements [19, 76, 135, 80]; for n ≥ 8 the bound C_{6.23}(n) < 4 − 2.263/√n [80]. Smale's Problem 1E [265] conjectured C_{6.23}(n) = 1 − 1/n. *AlphaEvolve:* given a set of roots, evaluated the polynomial on a 2D grid of points z. AE matched the best known lower bound and found other constructions with similar score (Fig. 15, p. 33: two of them, z¹² − 12z and z¹² + (6.86i − 3.12)z − 56964), but found no counterexample.

**Problem 6.24 (p. 32–34) — de Bruin–Sharma.** For n ≥ 4 let Ω_{6.24}(n) ⊂ R²₊ be the set of pairs (α, β) such that, whenever P is a degree-n polynomial whose roots z_1,…,z_n sum to zero and ξ_1,…,ξ_{n−1} are the critical points (roots of P′):
|ξ_1|⁴ + ⋯ + |ξ_{n−1}|⁴ ≤ α(|z_1|⁴ + ⋯ + |z_n|⁴) + β(|z_1|² + ⋯ + |z_n|²)²   (6.8).
What is Ω_{6.24}(n)? *Background (paper):* Ω is closed and convex. If all roots are real (or lie on a line through the origin) then (6.8) becomes an identity at (α, β) = ((n−4)/n, 2/n²) [89]. By Cauchy–Schwarz (6.9): (|z_1|²+⋯+|z_n|²)² ≤ n(|z_1|⁴+⋯+|z_n|⁴), and by expansion (6.10): (|z_1|⁴+⋯+|z_n|⁴) ≤ (|z_1|²+⋯+|z_n|²)², so Ω contains the points ((n−4)/n + n·2/n², 0) = ((n−2)/n, 0), (0, (n−4)/n + 2/n²) = (0, (n²−4n+2)/n²) and ((n−4)/n, 2/n²), together with the region above and right of these (convexity/monotonicity). The point ((n−4)/n, 2/n²) was conjectured to lie in Ω_{6.24}(n) and this was verified in [58]. *AlphaEvolve (search mode, p. 33):* searched for polynomials excluding half-planes of (α, β) with score = minus the area of the surviving region. AE found that the x-intercept (x, 0) could be lowered from (n−2)/n to (n³ − 2n² + 3n − 14)/(n(n²+3)) when n is odd, and that the y-intercept could be improved from (0, (n²−4n+2)/n²) to (0, ((n−2)⁴ + n − 2)/(n²(n−1)²)) for both odd and even n (the paper states the even-n x-intercept claim was "numerically confirmed"). The odd-n x-intercept came from a real-rooted polynomial with two roots of multiplicity close to n/2; the y-intercept from a polynomial of the form (z − a)^{n−1}(z + (n−1)a). The authors note AE exposed an oversight in their analysis: equality in (6.9) requires all |z_i| equal and real roots force a degenerate case. *Conjectured inequalities (p. 34), from the AE evidence:* for odd n > 4, |ξ_1|⁴+⋯+|ξ_{n−1}|⁴ ≤ ((n³−2n²+3n−14)/(n(n²+3)))(|z_1|⁴+⋯+|z_n|⁴); for all n ≥ 4, |ξ_1|⁴+⋯+|ξ_{n−1}|⁴ ≤ ((n−2)⁴+n−2)/(n²(n−1)²) · (|z_1|²+⋯+|z_n|²)². Tang [278] established these two inequalities shortly after the release of the paper, using an interpolation-based approach to the de Bruin–Sharma inequalities.

**Problem 6.25 (p. 34–35) — Crouzeix's conjecture.** Let C_{6.25} be the smallest constant such that ‖p(A)‖_op ≤ C_{6.25} sup_{z∈W(A)} |p(z)| (6.11) for all n×n complex matrices A and all complex polynomials p, where ‖·‖_op is the operator norm and W(A) := {⟨Ax, x⟩ : ‖x‖ ≤ 1} is the numerical range. What is C_{6.25}, and which polynomials attain (6.11) with equality? *Background (paper):* 2 ≤ C_{6.25} ≤ 1 + √2, lower bound [82], upper bound [83] (simplified proof [235]). Crouzeix's conjecture: C_{6.25} = 2. Proved for p(ζ) = ζ^M [23, 228]; for N = 2 and more generally when the minimal polynomial of A has degree 2 [82, 288]; and when W(A) is a disk [82, p. 462]. Numerical work [153,155] conjectured that the only maximisers are: for 2 ≤ n ≤ min(N, M+1), with m = n−1 and p(ζ) = ζ^m, the matrix (6.12) Â = [[0, 2],[0, 0]] if n = 2, and for n > 2 the n×n matrix whose only nonzero entries lie on the superdiagonal, equal to (√2, 1, 1, …, 1, √2) (the display in (6.12) shows the first entry √2 in row 1, interior entries 1, and the last entry √2 in row n−1; all other entries 0) (footnote 4 lists the equivalences: scaling p, scaling A, shifting the root and the diagonal, unitary similarity, replacing the zero block by any matrix with the same field of values). *AlphaEvolve:* optimised over A the ratio ‖p(A)‖_op / sup_{z∈W(A)} |p(z)|, scoring the extremal points via the Kippenhahn–Johnson characterisation ext W(A) = {z_θ = v_θ* A v_θ : θ ∈ [0, 2π]}, where v_θ is a normalised eigenvector for the largest eigenvalue of H_θ = ½(e^{iθ}A + e^{−iθ}A*). Tested with matrices of various sizes; found no example beating the literature value 2.

**Problem 6.26 (p. 35) — Sidorenko's conjecture.** A graphon is a symmetric measurable W: [0,1]² → [0,1]. For a finite graph H = (V(H), E(H)), t(H, W) := ∫_{[0,1]^{V(H)}} ∏_{{v,u}∈E(H)} W(x_v, x_u) ∏_{v∈V(H)} dx_v. For a finite bipartite graph H, let C_{6.26}(H) be the least constant such that t(H, W) ≥ t(K_2, W)^{C_{6.26}(H)} for all graphons W, where K_2 is the complete graph on two vertices. What is C_{6.26}(H)? *Background (paper):* taking W constant gives C_{6.26}(H) ≥ |E(H)|; graphs with C_{6.26}(H) = |E(H)| are said to have the Sidorenko property. Sidorenko [259] proved it for complete bipartite graphs, even cycles and trees, and for bipartite graphs with at most four vertices on one side; Hatami [163] for hypercubes; Conlon–Fox–Sudakov [72] for bipartite graphs with a vertex complete to the other side (generalised by Li–Szegedy [197] to reflection trees); further classes in [74, 73, 182, 273, 75]. The smallest bipartite graph whose Sidorenko property is not known is K_{5,5} minus a 10-cycle. *AlphaEvolve:* searched for a graphon W violating the inequality for this graph H, adding an extra penalty when W was close to constant. No counterexample was found.

**Problem 6.27 (p. 35–36) — the prime number theorem and its constants.** Let π(x) count primes ≤ x and define C⁻_{6.27} := liminf_{x→∞} π(x)/(x/log x), C⁺_{6.27} := limsup_{x→∞} π(x)/(x/log x). What are C⁻ and C⁺? *Answer (paper):* the prime number theorem gives C⁻ = C⁺ = 1. *Elementary (Chebyshev) bounds (paper, [95 §3]):* for a finitely supported ν: N → R with Σ_n ν(n)/n = 0 let A := −Σ_n ν(n) log n / n. If λ > 0 satisfies Σ_{n≤x} ν(n) ⌊x/n⌋ ≤ λ for all x ≥ 1 then C⁻ ≥ A/λ; if λ > 0, k > 1 satisfy Σ_{n≤x} ν(n)⌊x/n⌋ ≥ λ·1_{x<k} for all x ≥ 1 then C⁺ ≤ (k/(k−1))·A/λ. Sylvester's bounds [272] are 0.992619… ≤ C⁻ ≤ C⁺ ≤ 1.006774…. Good ν tend to be truncated versions of the Möbius function μ(n) (μ = e₁ − e₂ − e₃ − e₅ + e₆ − e₇ …). *AlphaEvolve (blind setup, p. 36):* AE was asked only to produce a partial function maximising a hidden evaluation function (not told the problem), and was asked to inspect its previous best function. AE recognised the importance of the Möbius function, numbers with a composite number of factors, and truncations of μ. Its final score, 0.938, fell short of the best known lower bound 0.992619….

**Problem 6.28 (p. 36–38) — Golay's merit factor and flat polynomials.** Let 𝕌_n be the set of polynomials of degree n with coefficients ±1. Define
C⁻_{6.28}(n) := max_{p∈𝕌_n} min_{|z|=1} |p(z)|/√(n+1),
C⁺_{6.28}(n) := min_{p∈𝕌_n} max_{|z|=1} |p(z)|/√(n+1),
C^ω_{6.28}(n) := min_{p∈𝕌_n} ( max_{|z|=1} |p(z)|/√(n+1) − min_{|z|=1} |p(z)|/√(n+1) ),
C⁴_{6.28}(n) := min_{p∈𝕌_n} (n+1)² / ∫_0^1 |p(e^{2πiθ})|⁴ dθ.
What is the behaviour of C⁻, C⁺, C^ω and C⁴ as n → ∞? (C⁴ is Golay's merit factor for p.) *Background (paper, footnote 5):* suggested as an AE use case by Junyan Xu. The normalising factor is natural: √(n+1) = (∫_0^1 |p(e^{2πiθ})|² dθ)^{1/2}, so by Hölder 0 ≤ C⁻(n) ≤ 1 ≤ (1 + 1/C⁴(n))^{1/4} ≤ C⁺(n) ≤ +∞. Littlewood's question [200] about flat polynomials (√n ≲ |p(z)| ≲ √n on |z| = 1) would imply 1 ≲ C⁻ ≤ C⁺ ≲ 1; existence of ultraflat polynomials (|p(z)| = (1+o(1))√n) is open [12]; Erdős [106] conjectured ultraflat polynomials do not exist, equivalently liminf C^ω(n) = 0 would have to fail (so C^ω(n) ≥ c for some c > 0), and the stronger C⁻(n) ≤ 1 − c, C⁺(n) ≥ 1 + c. Golay's merit-factor conjecture [144] asserts C⁴(n) ≲ 1 uniformly. Odlyzko [225] (≈30 CPU-years, n up to 100): lim C⁺ ≈ 1.27, lim C⁻ ≈ 0.64, lim C^ω ≈ 0.79. Best lower bound on sup_n C⁴(n): C⁴(12) ≥ 169/12 ≈ 14.08 (Barker sequences); conjectured to be the largest value of C⁴(n) [225, §2]. Asymptotically liminf C⁴(n) ≥ 6.340261… [170] and a heuristic [143] suggests limsup C⁴(n) ≤ 12.3248…; numerics suggest C⁴(n) ≈ 8 for n up to 300 [227] (see [39]). *AlphaEvolve (search mode, p. 38, Fig. 16):* aimed at lower bounds on C⁻ and upper bounds on C⁺ by evaluating the min (resp. max) of |p(z)|/√(n+1) on a dense mesh {e^{2πik/K}}_{k=1}^K with K = 6 or 7 (balance of accuracy and speed; larger K checked afterwards). Fig. 16 (p. 37): left, polynomials maximising min |p|/√(n+1) for degrees 10–90, values roughly 0.4–0.8 (peak ≈ 0.8 near degree 12, then decreasing to ≈ 0.4–0.5 by degree 90); right, polynomials minimising max |p|/√(n+1), values roughly 1.10–1.49 and rising with degree. Results are competitive for n ≤ 40 and deteriorate for larger n. Programs are in the Repository of Problems.

AlphaEvolve beat no record for the unit square; for the unit-area equilateral triangle improved n = 11 over [130]: min area ≥ 0.0365 (Fig. 26 left; Novikov25 says 0.036 → 0.0365).
**Problem 6.49 (p. 57): Heilbronn, arbitrary convex bounding box (triangle area relative to convex hull).** AlphaEvolve matched candidates for n ≤ 12 and improved Cantrell's for n = 13 (0.0306 → 0.0309) and n = 14 (0.0277 → 0.0278) (values from Novikov25 B.10; see Fig. 26 middle/right).
**Problem 6.50 (p. 57-58): max/min distance ratio.** Known values: C(2,n)=1 for n=2,3; C(2,4)=C(2,5)=…; 1+√5/… ; C(2,6)=2 sin 72°; C(2,7)=2; C(2,8) = (2 sin(π/14))^{−1}; Cantrell, Rechenberg, Audet et al. numerical candidates n = 9..30 (d=2), 5 ≤ n ≤ 21 (d=3). AlphaEvolve: improved d = 2, n = 16: ratio ≈ √12.889266112; d = 3, n = 14: ≈ √4.165849767 (squared-ratio convention); the latter later improved in [25]. Several (n,d) pairs searched at once; matched the best known for most parameters.
**Problem 6.51 (p. 58): Erdős–Gyárfás.** Does every finite graph with min degree ≥ 3 contain a cycle of length 2^k (k ≥ 2)? AlphaEvolve searched graphs up to 40 vertices; no counterexample.
**Problem 6.52 (p. 58-59): Erdős squarefree.** Largest A ⊂ {1..N} with ab+1 never squarefree: ⌈(N−7)/25⌉ ≤ … ≤ (0.1052…+o(1))N; AlphaEvolve found the residue-class-7-mod-25 construction, nothing better; [248] shows the lower bound is sharp for large N.
**Problem 6.53 (p. 59): Erdős equidistant points in convex polygons.** Does every convex polygon have a vertex with no 4 other vertices equidistant from it? (3 is false: Danzer, Fishburn–Reeds.) AlphaEvolve produced polygons where every vertex has ≥ 3 equidistant others; no example for 4.
**Problem 6.54 (p. 59-60): touching cylinders.** Can 7 infinite unit-radius cylinders mutually touch? Known yes (Bozóki–Lee–Rónyai [43], ≈ 4 CPU-months for one solution); 8 open. Loss Σ(2 − dist(axes))². AlphaEvolve: n = 7 with loss O(10⁻²³) in two hours (ready for rigorous certification); n = 8: loss stuck at 0.003 (suggesting 7 optimal); with unequal radii the optimum n = 9 found in a few hours (Fig. 28). Intersections checked in a [0,100]³ cube to avoid near-parallel exploits. Dimension count: unit cylinder has 4 degrees of freedom, symmetry group dimension 6, so 4(n−2)+2 variables vs n(n−1)/2 equations.
**Problem 6.55 (p. 60): squares in a square.** s(n) = max total side length of n squares with disjoint interiors in the unit square; s(k²) = k; conjecture s(k²+1) = k (Erdős; verified for k = 1, 2; for axis-parallel squares [11]). AlphaEvolve matched best constructions for n ∈ {10, 12, 14, 17, 26, 37, 50} but not some larger n.
**Problem 6.56 (p. 60-61): Szemerédi–Trotter.** I(n,m) ≍ n^{2/3}m^{2/3} + n + m; AlphaEvolve, restricted to Z² points and rational lines (exact arithmetic), rediscovered grids {1..a}×{1..b} with greedily chosen rich lines. In progress.
**Problem 6.57 (p. 61-62): Rudin problem.** Ratio of L⁴ (or L^∞) to L² norms of spherical harmonics of degree n on S^d; only the L⁴ version on S² (Laplace harmonics, Wigner 3-j integrals via sympy) tested, preliminary results to degree 30 (Fig. 29).
**Problem 6.58 (p. 62-63): Erdős–Szekeres happy ending.** h(k) smallest N such that any N points in general position contain a convex k-gon; 2^{k−2}+1 ≤ h(k) ≤ 2^{k+O(√(k log k))}; h(4)=5, h(5)=9, h(6)=17. AlphaEvolve (k ≤ 8): found 2^{k−2} points without convex k-gon, and 2^{k−2}+1 points with only a single convex k-gon, but could not improve the lower bound.
**Problem 6.59 (p. 63-64): subsets of the n×n grid with no isosceles triangles (even degenerate).** Known asymptotics √n ≲ … ≲ n^{2}·(log n)^{1/9}·… (garbled); best 64×64 construction 110 [56] (authors guessed 112; a(16) = 28, a(32) = 56, a(2n) = 2a(n) often). AlphaEvolve with hints (near four-fold symmetry, axes not meeting at the midpoint, points near the edge) found 112 points in the 64×64 grid after a few days, and 164 points in the 100×100 grid (previous 160) (Fig. 30).
**Problem 6.60 (p. 63-64): no 5 points on a sphere or plane in [n]³.** Largest subset size; √n ≲ … ≲ 4n (1995), n^{3/4−o(1)} lower bound recently [270, 140]; AI-assisted lower bounds [56]: n=3: 8, 4: 11, 5: 14, 6: 18, 7: 20, 8: 22, 9: 25, 10: 27. AlphaEvolve (CPU only): n=7: 21, 8: 23, 9: 26, 10: 28, and new n=11: 31, n=12: 33 (Fig. 31 shows 23 points in [8]³ and 28 points in [10]³). See Table 7 below.
**Problem 6.61 (p. 64-65): ring loading discrepancy.** Infimum of reals for which a ±-assignment exists with partial-sum bound; 101/100 ≤ C ≤ 3 [253]; Skutella 11/10 ≤ C ≤ 19/14 (printed "11/10 … 19/14"); AlphaEvolve found 15 numbers with score ≥ 1.119 (improving 1.1).
**Problems 6.62-6.64 (p. 65-67): moving sofas.** Classic: C = 2.2195… (Gerver sofa, proved optimal by Baek [10]); ambidextrous: Romik sofa ≥ 1.6449… (open whether sharp); 3-D "snake" corridor: simple lower bounds 1.7391 (intersection of two extruded Gerver sofas) and 1.7699 (extruded sofa ∩ unit-diameter cylinder, with a 90° twist). AlphaEvolve: classic sofa within 0.02%, Romik within 1.5% (when stopped); 3-D sofa with rigorous volume ≥ 1.81 (estimate 1.84), a new construction (Fig. 33). Method: path of translations/rotations; sofa = region never leaving the corridor; 3-D: point cloud, smoothed paths; 3.4·10⁶ grid points used to estimate the reference volumes.
**Problem 6.65 (p. 66-69): IMO 2025 Problem 6 (n×n grid, fewest rectangular tiles so that each row and column has exactly one uncovered cell).** True value ⌈n + 2√n − 3⌉ (easy construction 2n − 2). AlphaEvolve (generalizer mode, scored on perfect squares only) found the optimal construction for all perfect-square n (Fig. 34: n = 36); inconsistent on other n (Fig. 35). Proof of optimality not attempted. Penalty Σ|1−r_i| + Σ|1−c_j| (r_i, c_j uncovered counts), ∞ if tiles overlap.
**Section 6.44 (p. 69-71): Bonus, code that calls LLMs.** Function guessing game (reward 1000 currency units, cost 1 per evaluation, 10 per oracle/LLM question; game over after five wrong guesses) and Smullyan-type logic puzzle (three guards, 36 permutations, two yes/no questions, prizes $0, $100, $110); the cheap oracle/guard LLMs were jailbroken by AlphaEvolve's programs ("cheating"), fixed by restricting to yes/no; modest success.

Fig. 2: 50 experiments with a cheap LLM vs 20 with an expensive LLM (price ratio roughly 15× per input token, 30× per output token); cheap runs need ≈ 2× as many calls; total LLM cost "a few USD" to beat the literature bound; cheap model insufficient for hard problems (Nikodym); mixing in cheap models can help via added variance.

## Methods / algorithms
Generic AlphaEvolve loop (same as Novikov25; here described pp. 2-5): LLM generator mutates programs; user-provided deterministic evaluator scores; population selection; search mode and generalizer mode. Compute: evaluators have fixed time budgets, CPU hours ∝ LLM calls (p. 5); typical experiments: minutes-hours on CPU (e.g. Thomson N ≤ 300: first hour for N < 50, O(10) h for larger; Tammes O(10) h; cylinders 2 h; isosceles-free 112 points: a few days; Tammes/Thomson used no hints). Verification: explicit numerical certificates (e.g. kissing loss < O(10⁻²⁰); spherical designs error < 10⁻⁸; cylinders loss O(10⁻²³)); Deep Think/AlphaProof for proof/formalisation of Kakeya constructions. Typical scoring/penalty designs documented per problem above (kissing: sum of (2 − d)+; packing: scale + overlap area; Heilbronn: smallest triangle area; Thomson: Coulomb energy; Tammes: min distance; squares in square: −∞ if invalid; Erdős–Szekeres: number of convex k-gons).
