## Abstract
Two geometric spaces are in the same topological class if they are related by certain geometric deformations. We propose machine learning methods that automate learning of topological invariance and apply it in the context of knot theory, where two knots are equivalent if they are related by ambient space isotopy. Specifically, given only the knot and no information about its topological invariants, we employ contrastive and generative machine learning techniques to map different representatives of the same knot class to the same point in an embedding vector space. An auto-regressive decoder Transformer network can then generate new representatives from the same knot class. We also describe a student-teacher setup that we use to interpret which known knot invariants are learned by the neural networks to compute the embeddings, and observe a strong correlation with the Goeritz matrix in all setups that we tested. We also develop an approach to resolving the Jones Unknot Conjecture by exploring the vicinity of the embedding space of the Jones polynomial near the locus where the unknots cluster, which we use to generate braid words with simple Jones polynomials.

## Notation and conventions
- (p. 6) Knots are represented as closed braid words in B_n with generators σ_i ↦ integer i and σ_i^{-1} ↦ −i; two braid words differing by conjugation w → gwg^{-1} or stabilization w → wσ_n^{±1} (Markov moves) describe the same knot; "two knots are related by ambient isotopy iff one braid representation can be brought to the other using only the two Markov moves and the two braid relations." Relations (2.3) σ_iσ_j = σ_jσ_i (|i−j|>1), (2.4) σ_iσ_{i+1}σ_i = σ_{i+1}σ_iσ_{i+1}.
- (p. 5) Equivalence class K_i, representatives K_i^α; embedding f_θ: K_i^α ↦ m_i ∈ R^n with m_i ≠ m_j for i≠j; m_i = learned invariant.
- n_letters = length of braid word, n_strands = number of strands, n_scrambles = number of random Markov moves applied to seed braid (p. 16). Braid length in the figures = n_letters ("Braid length: 25…40" panels).
- (p. 20) vol(K) accuracy: validation accuracy where decoder output K′ for a test knot K is counted correct if |vol(K) − vol(K′)| ≤ 10^{-5} (hyperbolic volume computed with SnapPy). (Counts equal volume as proxy for equivalence; only valid for hyperbolic knots.)
- (p. 14) "simple" Jones polynomial: small span (largest minus smallest power). In-distribution vs out-of-distribution test sets defined p. 17.

## Key equations and quantitative claims outside numbered statements
- (2.7) Triplet loss L(A,P,N) = max(‖f(A) − f(P)‖² − ‖f(A) − f(N)‖² + κ, 0) (p. 9); semi-hard triplets chosen online (negative farther than positive but within margin κ).
- (2.8) Centroids c_i = (1/N) Σ_α f_θ(K_i^α); (2.9) centroid loss L = (1/M) Σ_{i=1}^M (1/N) Σ_{α=1}^N ‖c_i − f_θ(K_i^α)‖² (M classes, N representatives per class); (2.10) with repulsion: + λ Σ_{i,j} max(κ − ‖c_i − c_j‖, 0) (p. 10; ⚠ the text says (2.9) is "zero iff all elements from the same class get mapped to the same point" but as printed argument of loss is L(c_i, K_j^α) mixing indices i/j).
- (2.6) CNN: first layer 1D conv with filter size = braid length, stride 1, periodic boundary conditions, so output contains all cyclic conjugates (p. 8).
- (2.13) temperature sampling p_i = softmax(ℓ_i/T); beam size 100 (p. 15).
- Data (p. 16): ablation datasets: 50,000 equivalence classes × 20 representatives, 5-strand braids (before stabilization), n_letters ∈ {20,25,30,35,40,45,50}, n_scrambles ∈ {5,10,15,20}; test/validation: same parameters with 25 equivalence classes; "about 10GB of data", train sets 150–400 MB. Seed braid via RandomKnot (Algorithm 6 of [7] = GHRS20) with M = 1; shortest braid word of each class used as the decoder target; braids padded to same length via stabilization (so n_strands may vary).
- Contrastive experiments (p. 17): dataset 50k classes, braid length 30, 5 strands, 20 knots per class, 10 scrambles. MLP: 2 hidden layers × 64 nodes, tanh, 7k parameters, 300 epochs, Adam lr 1e-3. CNN: 1D conv 64 filters leaky ReLU + 2-layer MLP of 64 nodes tanh, 130k parameters, 500 epochs, Adam lr 1e-4. Batch size 128. 16-dim embedding but PCA shows only 1–2 dims used. Early stopping best; models overfit. In-distribution test: 15 train representatives per class, 5 held out; out-of-distribution: 50% of classes held out. "in-distribution generalization works very well"; out-of-distribution clustering "a bit less tight" (Figs 2–3, qualitative).
- Generative ablation (p. 20): Int2Int [26] Transformer; batch 64, 25 epochs of 300,000 knots each; encoder and decoder embedding 256 dim, positional embedding, 4 layers, 8 heads, 1 feed-forward layer, ReLU; validation every 200 batches (≈ 23 per epoch). Results: vol(K) accuracy decreases monotonically with n_scrambles (Fig. 4); no clear correlation with braid length (Fig. 5). For n_letters=30, n_scrambles=10: untrained network clustering first 2 PCs ≈ 50% explained variance (0% vol accuracy), trained ≈ 11% explained variance; vol(K) test accuracy 92.4% for trained network.
- Long run (p. 22): n_letters = 30, n_scrambles = 15, > 250 epochs. Train loss decreases steadily while vol(K) accuracy peaks early then drops (overtraining); explained variance of top PCs: over-trained train 0.158, over-trained test 0.114, well-trained train 0.113, well-trained test 0.120 (Fig. 6 titles). "training for a longer time leads to overtraining that hurts performance."
- Transfer learning (Table 1, p. 24): model trained at n_scrambles=5 generalises to more scrambles with accuracy 5–10% lower.
- Teacher–student (pp. 24–27): contrastive students: 2 layers × 64 neurons tanh. Transformer teachers: use embedding-layer outputs, concatenated embedding vectors of output tokens, PCA, first 200 PCs (≈ 80% explained variance) as labels; three independent teachers trained on braids of size 25 and 30, 2–4 h on an NVIDIA RTX 3090. Students: four-layer FFNN width 1024, batch norm, GELU, ≈ 2.5M parameters (≈ a quarter of teacher), 800 epochs, Adam (PyTorch defaults). Findings: students predict teacher embedding from braid words (baseline) and from the Goeritz matrix almost as well; to much lesser extent from knot Floer homology data; contrastive teachers also from vol, ν, τ, Seifert genus, Jones; "None of the teacher NNs seem to make use of the Alexander Polynomial" (p. 33), "perhaps a bit surprising" given det(Goeritz) = Alexander at −1 (p. 25). Invariants inputs: scalar [vol, ν, τ, g], matrix (Goeritz, knot Floer homology), polynomial (Alexander, Jones) (p. 11). Student loss values only in plots (Figs 7, 9).
- Jones Unknot search (pp. 27–32): training set 10^6 inequivalent braid words of length 30 (generator draw uniform in [−N,N], N = 4, so ≤ 5 strands, one-component); Jones polynomials via SageMath; five smallest knots (0_1, 3_1, 4_1, 5_1, 5_2) added by hand as 30-crossing 4-strand representatives; unique Jones-polynomial labels; coefficients from a^{−78}t^{−78} to a^{76}t^{76}, zero-padded vector of length 155. Transformer (Int2Int): 256-dim embedding, 4 layers, 8 heads per encoder/decoder, ≈ 5M parameters each, dictionary size ≈ 1000 (integers encoded in base 1000), 450 epochs of 300k samples, batch 32, ≈ 3 days on RTX 4090. 400k knots generated (100k per sampling method plus baseline 100k random braid words); no counterexample found: "We generate several 100k knots, but none of them have trivial Jones Polynomials" (p. 33).
- Sampling parameters: Gaussian noise added to encoder output, σ ∈ [0.1, 0.5] increased linearly every 1000 knots, σ < 0.1 mostly unknots; average generated length ≈ 40 for small σ (training 30), simplifies to about half as many crossings. Trajectory sampling: piecewise linear paths γ_1…γ_4 in the 256-dim embedding space from the unknot to 3_1, 4_1, 5_1, 5_2 (10 points per path; 3 along first leg, 7 along second); 5120 braids per knot from γ_1,γ_2; 1000 random γ_3 and 1000 γ_4 paths (out of 32640); ≈ 100k braids in total. Temperature + beam: T ∈ [0.01, 1.40], 100 braid words per temperature via beam (size 100) = 100k; sharp length transitions near T=0.2–0.4 (to 10 and 3) and at T≈1; nonsensical words (e.g. [1,2,−98111]) replaced by [1,2,−4].
- Statistics of generated knots (Fig. 11, pp. 31–32): random braids all distinct; generated sets far fewer distinct words (lowest for path sampling); all methods give similar percentage of inequivalent hyperbolic links; ≈ 80% of generated are hyperbolic (vs essentially all of random ones) and of those ≈ 90% describe the same knot/link; one-component fraction much higher than random; about 10% of one-component knots with different volumes share Jones polynomials.

## Methods / algorithms
1. (pp. 16–17) Data: RandomKnot seed braid (n_letters, n_strands=5, M=1); apply n_scrambles random Markov moves to get 20 representatives; shortest = decoder target; stabilize to common length.
2. (pp. 8–10) Contrastive: encoder-only MLP or CNN with centroid loss (2.9–2.10) or semi-hard triplet loss (2.7); online centroids; PCA on 16-dim bottleneck.
3. (pp. 8–10) Generative: encoder–decoder Transformer, tokenised braids with one-hot (2(n−1)-dim) → n_emb embedding, positional embedding, end-of-sequence token, softmax over 2n+1 outputs; greedy / beam / temperature decoding; cross-entropy loss; target = fixed representative; validation by SnapPy volume.
4. (pp. 11–12, 24–27) Teacher–student invariant extraction (see Key quantitative claims); proposed (not performed) "subtract off" of student-predicted embedding to find new invariants.
5. (pp. 12–15, 27–32) Jones-unknot search: Transformer from Jones coefficient vector to braid word; sample vicinity of J=1 via Gaussian noise on encoder output, embedding-space trajectories, temperature+beam; check generated braid words' Jones polynomials.
Compute: contrastive networks tiny; Transformer teachers 2–4 h on RTX 3090 (generative); Jones model 450 epochs ≈ 3 days on RTX 4090.

## Stated limitations, open problems, future work
- Equivalent representations from deforming the embedded S^1 (polygonal curve in R^{3P}) not attempted (p. 6).
- "We have not carried out a systematic analysis" of subtracting known invariants to uncover new ones (p. 12).
- Future (p. 33): combine contrastive and generative losses; apply to 3-manifold classification; subtract student embeddings and apply symbolic regression/FunSearch; use synthetic data for ML-theory questions about learned features.
- The vol(K) check assumes equal volume ⇒ equivalent (p. 10–11: "it is highly unlikely" that a different class has the same volume; not proven). Overtraining observed in both setups (p. 24).
- Jones Unknot Conjecture: no counterexample found among several 100k generated knots (p. 33).
