## Abstract
Knotted molecules occur naturally and are designed by scientists to gain special biological and material properties. Understanding and utilizing knotting require efficient methods to recognize and generate knotted structures, which are unsolved problems in mathematics and physics. Here, we solve these two problems using machine learning. First, our Transformer-based neural network (NN) can recognize the knot types of given chain conformations with an accuracy of > 99%. We can use a single NN model to recognize knots with different chain lengths, and our computational speed is about 4500 times faster than the most popular mathematical method for knot recognition: the Alexander polynomials. Second, we for the first time design a diffusion-based NN model to generate conformations for given knot types. The generated conformations satisfy not only the desired knot types, but also the correct physical distributions of the radii of gyration and knot sizes. The results have several implications. First, the Transformer is suitable for handling knotting tasks, probably because of its strength in processing sequence information, a key component in knotting. Second, our NN can replace mathematical methods of knot recognition for faster speed on many occasions. Third, our models can facilitate the design of knotted protein structures. Lastly, analyzing how NN recognizes knot types can provide insight into the principle behind knots, an unsolved problem in mathematics. We provide an online website for using our models.

## Notation and conventions
- (p. 1–2) N = chain length (number of beads); knot types 0_1, 3_1, 4_1, 5_1, 5_2, 6_1, 6_2, 6_3 (eight classes); knots ≤ 6 minimum crossings (p. 11).
- (p. 5) N_ac = number of apparent crossings of a conformation projected onto a plane (differs from minimum crossing number N_c, e.g. 3 for 3_1, 4 for 4_1); Fig. 3 inset: a trefoil with N_ac = 258.
- (p. 4) L_p = persistence length (Table I: "L_p = 0 means no bending energy"); a = bond length unit in Vandans20 (L_p = 10a). Accuracy = fraction correctly classified (confusion matrices: columns = actual class, rows = predicted per Fig. 2 caption "horizontal coordinate represents the actual ground truth class, while the vertical coordinate represents the predicted"). ⚠ For Fig. 4 the caption says "x coordinate represents the actual ground truth class".
- (p. 8) Knot core: "the minimum portion of the chain that maintains the knot type"; L_k = number of beads in the knot core; R_g = radius of gyration. RMSD in units of bead diameter.
- (p. 5) Open chains: knot type defined after closing the ends by an optimised loop [61].

## Key equations and quantitative claims outside numbered statements
Recognition (pp. 1–5, Table I, Figs. 2–3).
- (p. 2) Data: Langevin simulations of ring chains with fixed knot type (knot type remains unchanged); 60,000 conformations per chain length (N = 100, 300, 500, 800, 1000) and knot type (8) = 2,400,000 total; per 60,000: 45,000 training, 5,000 validation, 10,000 test. Input feature: 6-dim vector = XYZ coordinates + bond vectors; training "typically takes 20 epochs".
- (p. 2) Test accuracy on seen lengths: N = 100: 99.9999% (Table I); average over seen lengths 99.39% (on test set, Table I). Generalization lengths tested: N = 80, 150, 437, 550, 821, 952 (confusion matrices Fig. 2; diagonal entries 0.9289 (N = 952, class 5₂) to 1.0 (image-verified 2026-11-12; ⚠ the earlier range 0.9420–0.9998 was wrong); e.g., N = 80 diagonals ≈ 0.9996–0.9998 ... 0.9937; N = 952 diagonals 0.9651–0.9996 — assignment of diagonals to knot types not verified).
- (p. 2–4) Comparison (Table I): N = 100: Vandans 99.59%, Sleiman 99.8%, this paper 99.9999%; N = 200: this paper 99.08%, Sleiman 99.6%; "our model does not perform as strongly when classifying N = 200" mainly because 5_1 only ≈ 95.2% (other knots avg 99.7%), attributed to "low variance in the data we collect for the 5_1 knots of length N = 200". Braghetto et al. (BKBO22) reached ≈ 80% at N = 512 after truncation (partition to N′ = 128), this paper 99.23%.
- (p. 4–5) Speed: 500 polymer knots with high apparent crossing numbers N_ac; ML model 1.36 ms per conformation (Fig. 3: total average time 0.68 s per 500) vs Alexander polynomial 6.24 s per conformation ⇒ "about 4500 times faster"; ML time insensitive to length/N_ac; Alexander cost dominated by an N_ac×N_ac determinant; HOMFLY cost exponential in N_ac. (⚠ Fig. 3 legend "Our Model (Average time = 0.68s)" is the total for 500 conformations as read; arithmetic 6.24/0.00136 ≈ 4588.)
Protein / open chains (pp. 5–6, Fig. 4).
- Open-chain polymer knots: dataset 10^6 samples of eight knot types, lengths 80–950; accuracy ≈ 99.9% (text) / "nearly 99%" (Fig. 4c caption average) ⚠ minor inconsistency. Transfer learning on AlphaKnot [62]: 139,950 protein knots in the database (trefoil 90,846 most abundant; 6_2 least with 166), 20% used as training set, learning rate 10^{-5}, one epoch: accuracy 97.9% (text) vs average ≈ 82.4% per Fig. 4d caption (⚠ the text and caption report different numbers — presumably 97.9% overall accuracy vs 82.4% class-averaged; not reconciled in paper). 6_2 degenerate (insufficient data).
Generation (pp. 5–9, Figs. 5–6).
- Diffusion model: DDPM training with Transformer replacing U-Net; condition = knot invariant (knot type) via cross-attention layers; trained on semi-flexible ring polymers with N = 80 using bond vectors as feature; noise schedule 1000 steps (T = 1000 → 0); generated bond vectors converted to coordinates by cumulative sum. Methods: conditional generation, Classifier Guidance (CG: separate classifier on noised knots; gradient of log-probability added to learned mean; guidance scale s), Classifier-Free Guidance (CFG, implicit classifier: randomly drop condition for 10% of data, guidance scale c_fg).
- Evaluation metrics (p. 6): (i) accuracy of achieving desired knot type, (ii) novelty (RMSD between generated and nearest training structure ≈ 4 bead diameters), (iii) diversity, (iv) physical correctness (knot core length L_k and R_g distributions). Findings: conditional (CG s = 0) and CG more accurate than CFG; accuracy lower for more complex knots (smaller conformational entropy); most frequent wrong output for 6_3 is 3_1. Generated L_k and R_g distributions agree with training data; R_g decreases with crossing number (Fig. 6d–e; CG with s = 10). Numerical accuracy values per knot type only in Fig. 6b (not numeric in text).
- (p. 9) Protein-knot generation idea: fix knot core residues of 1UAM, 1NS5, 1XD3 and generate the rest (supplementary).
- (p. 9) Feature discussion: "using spatial coordinates alone is sufficient, while including the bond vector improves the result"; bond vector alone fails with the plain Transformer but works with an MLP before the Transformer block; segment-to-segment writhe (StS) works, integral StA fails for flexible polymers.
- (p. 9) "We use mostly the same values for hyper-parameters in our models as those in the original Transformer and Diffusion model papers"; careful tuning might improve; including shorter lengths in training would improve generalization to smaller polymers.
Simulation (Methods, p. 10–11).
- FENE: V_FENE = −30ε (r_0²/σ²)·ln(1 − (r/r_0)²)... [text layer: "−30ε r0²/σ² ln(1−(r/r0)²) with r_0 = 1.5σ and ε = 1"]; WCA exclusion V_excl = 4ε[(σ/r)^12 − (σ/r)^6] + ε for r < 2^{1/6}σ else 0; Langevin: m dv_i/dt = −γv_i − Σ_j ∇V_tot + f_ri; velocity-Verlet in LAMMPS, NVT, γ = σ = m = ε = T = 1, 10^8 steps with Δt = 10^{−2}τ, free space (no confinement). No bending energy (L_p = 0).
- Model: Transformer encoder with sinusoidal positional embedding, [CLS] token, padding for variable lengths, linear classification layer (Fig. 1b); layer counts, heads, embedding size, batch size, optimizer are not given in the main text (⚠ referenced to supplementary/GitHub, not in PDF). Implemented in PyTorch; code and parameters on GitHub; online website provided.

## Methods / algorithms
1. (p. 10) Data: Langevin simulations of FENE–WCA flexible rings, fixed knot type, 8 knot types, N ∈ {100,300,500,800,1000}; 60,000 per (N, type) split 45k/5k/10k.
2. (p. 11) Classifier: 6-dim per-bead feature (xyz + bond vectors) → embedding + sinusoidal positional embedding → Transformer encoder (vanilla; masked padding, layer norm, attention) → [CLS] token → linear → 8 classes (Fig. 1b); ~20 epochs.
3. (p. 5–6) Open-chain/protein: train on 10^6 open coarse-grained chains (8 types, N 80–950), then transfer-learn on 20% of AlphaKnot with lr 10^{-5} for one epoch.
4. (pp. 6–7, Fig. 1c) Generator: DDPM with Transformer denoiser, cross-attention to topological invariant, 1000 steps; semi-flexible N = 80 rings (bond-vector feature), plus CG/CFG guidance; knot-core and R_g checked against Langevin ground truth.
5. Verification: classification on held-out test sets (10,000 per class per length) and unseen lengths; speed vs Alexander polynomial on 500 conformations; generation checked by a classifier(!)/ground-truth: the accuracy of the generated knot type is assessed with a knot-recognition procedure (⚠ not specified in the pages read whether via the trained classifier or Alexander polynomial).

## Stated limitations, open problems, future work
- "our model does not perform as strongly when classifying N = 200" (p. 2); "including shorter lengths in the training stage of our model can improve generalizing accuracy for smaller polymers" (p. 9).
- Maximum length N = 1000 "is solely limited by the device's memory" (p. 2).
- "For our generative models, generation accuracy is not as stunning as that of our classification model"; suggested: incorporate prior knowledge of knot invariants/over–under passing, KMT reduction + 2-D projection, latent diffusion (pp. 9–10).
- 6_2 protein knots degenerate due to insufficient training data (p. 6). Hyper-parameters mostly default, "careful tuning … might result in an even better overall accuracy" (p. 9).
- Many-to-one problem: Alexander polynomial same for different knot types; analysing how ML recognizes knots may give insight into knot principles (p. 10).
