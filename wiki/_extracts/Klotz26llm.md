## Abstract
This work summarizes some updates to the ropelength problem, concerning the shortest possible contour length of a unit-thickness knot, that were derived with the assistance of ChatGPT-5.6 Luna. The first of two main results is that the universal lower bound for a knot with crossing number C has been improved from L ≥ 1.105 C^{3/4} to L ≥ 2.0996 C^{3/4}, achieved by further separating local and global terms in an optimization integral. The second main result is a bound relating ropelength to stick number (s), such that L ≥ π(s − 1). This implies stronger lower bounds for the ropelengths of at least 41 torus knots, and a specific class of pretzel knots. Other results include an improved packing-based lower bound for T(Q, Q) links and an optimized standard parameterization for torus knots. There were many problems for which the LLM was unable to render assistance, for example in reducing the numerical coefficients or scalings of known universal upper bounds.

## Notation and conventions
- **Ropelength convention: LENGTH / RADIUS (unit-radius tube).** "the ropelength L as the minimum ratio of the contour length of the knot to its thickness, where thickness is defined as the radius of the smallest circle passing through any three points on the knot [1] ... allowing the knot to be surrounded by a thick tube of radius 1" (p. 1–2). §2.1: "thickness (tube radius) Δ > 0 ... Rop(K) = Len(K)/Δ ... K has a non-overlapping unit-radius normal tube" (p. 12). §3.1: "The formulas below use the unit-radius convention" (p. 18). Hopf-link bound a_u ≥ 78.5 (p. 2) uses the same convention (ropelength of Hopf link 8π). ⚠ Compare DDS04 (length/diameter, p. 22 there) which gives half of these numbers.
- C = crossing number c(K) = Cr(K); s = stick number; sb = superbridge index; b = bridge number; T(P,Q) torus knot/link, P > Q, crossing number C = P(Q−1) (T(P,2): C = P); T(q,p) used in §3 with 2 ≤ p < q, C = q(p−1) (p. 20).
- E_N = normal energy, E_s = symmetric energy, ⟨C⟩ average crossing number (Buck–Simon chain 11 L^{4/3} ≥ E_N ≥ E_s ≥ 4π⟨C⟩ ≥ 4πC, p. 12); Möbius energies E_s, cross-energy conventions once-counted E_c^{(1)} vs twice-counted E_c^{(2)} (p. 43).
- A_W(N): area of a Wegner packing of N unit disks; convex hull lower bounds (p. 7–8, 40–42).
- LLM labels: "Author's note" paragraphs are by A. Klotz; unlabelled derivation text is LLM-written (p. 10).

## Numbered statements
- **Lemma 1 (p. 19) — Thick-curve polygonal approximation (from Litherland–Simon–Durumeric–Rawdon [11]; LLM-written statement, rigorous-quoted).** Let γ be an embedded closed curve with length ℓ and thickness τ > 0. There is a polygonal knot P ambient isotopic to γ with N(P) ≤ ℓ/(πτ) + 1 edges. *Geometric mechanism (as printed):* partition γ into consecutive subarcs of arclength ≤ πτ and join consecutive partition points by chords; the thickness condition ensures no self-intersection and isotopy. Remark 1 (p. 19): "the nontrivial part of the lemma is the isotopy assertion ... should be cited as the polygonal-approximation theorem rather than presented as an elementary consequence".
- **Theorem 1 (p. 19) — Stick-based ropelength lower bound (LLM-claimed, derived from Lemma 1; short rigorous derivation).** For every nontrivial knot type K, Rop(K) ≥ π(stick(K) − 1). More generally, if a rigorous lower bound s_0 ≤ stick(K) is known, then Rop(K) ≥ π(s_0 − 1). Proof (p. 19–20): apply Lemma 1 to any representative: s(K) ≤ Len/(π Thi) + 1, rearrange, take infimum. Remark 2 (p. 20): a polygonal construction with s edges gives only stick ≤ s and does not imply Rop ≥ π(s−1); one needs a proof that no polygon with fewer edges exists.

## Methods / algorithms
1. (p. 1–2, 10) Extended prompting sessions with ChatGPT-5.6 Luna; LLM-written LaTeX; Copilot used for an attempted referee report (it "lied twice" about compiling it); ChatGPT then asked to generate numerical evidence and a Python script (ancillary, not in PDF).
2. (§2) Buck–Simon energy chain with refined packing estimate: split E_N(x) = local (arc length ≤ 3 each side) + far; local bound 1/4 per unit length ⇒ 3/2; far part bounded via a layer-cake (cumulative far length M_x(R) ≤ min{S, F(R) − δ}); one-variable numerical maximization of Q(L).
3. (§3) Thick-curve inscribed polygon (Lemma 1) ⇒ Theorem 1; apply to torus knots with Jin's stick numbers, pretzel/Montesinos families via bridge/stick index inequalities.
4. (§3.9) Parametric construction of P(2,3^N): modules on a circle, asymmetric helical pairs, Bézier connectors, resampling; ropelength estimated numerically.
5. (§4) Parametric torus curves with radial/vertical scaling; exact lengths via Appell F₁ and numerical thickness (curvature and doubly critical distance); limiting-slope analysis.
6. (§5) Shell-capacity model for concentric helix donuts (Klotz–Thompson), integrals over shells; rigorous cylinder no-overlap lemma; polygonal-isoperimetric refinement of the hull lower bound.
7. (§6) Rawdon–Simon argument extended to links with shell-volume packing and component count.
