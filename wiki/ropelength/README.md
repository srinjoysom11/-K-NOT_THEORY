# Ropelength

Ropelength Rop(K) = minimum length of a curve of type K carrying an embedded tube of unit thickness. **Convention trap:** "unit thickness" means unit *radius* in most sources here (R-units) and unit *diameter* in [DDS04] (D-units, values halved). All pages in this folder use R-units and double D-unit values. Lattice link: Rop ≤ 2·Len(K).

* [lower-bounds](lower-bounds.md) — absolute constants (best proved: 31.32 [DDS04]), c^{3/4} law, alternating knots linear, links, per-paper convention table.
* [upper-bounds](upper-bounds.md) — quadratic bounds ([CKS01], [CFM02], [HKNO14]), O(c ln⁵ c) [DEPZ09], linear families (2-bridge), C^{3/4} torus constructions ([KT25], [Klotz26tqq]).
* [numerics](numerics.md) — tight-knot values, the 12-crossing census [KA23], satellites and torus knots [KM21], pearl necklaces vs FCC [Klotz26pearl], LLM-assisted claims [Klotz26llm].

Existence: minimizers exist in every link type and are C^{1,1} ([CKS01] Thm 7).
