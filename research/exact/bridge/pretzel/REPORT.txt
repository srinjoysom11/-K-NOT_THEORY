PRETZEL BRIDGE EXPERIMENT: short lattice polygons for pretzel knots P(p1..pr), r>=4
Goal: find polygon with Len < 16*r-8 of the verified knot type (refutes Len(K) >= 16 b(K) - 8).

CONSTRUCTION
- spherogram.RationalTangle(1, p) for each column (vertical twist with p half-twists),
  pretzel = (T1 + ... + Tr).numerator_closure(). Used as-is, no simplification before seeding.
- Checks per knot (build_pretzels.py): 1 component, crossings = sum|pi| (all matched).
- Alexander polynomials from research/code/alexander.py on the PD code after simplify('global').
  Checks: P(3,3,3,3,3) gives Delta(-1)=405 = 5*3^4 (determinant), consistent with pretzel theory.
- Did not use spherogram Link.alexander_polynomial(): it needs Sage (not available here).
- Did not run exterior().identify(); volume comparison used instead.

COMMANDS (run from research/exact/bridge/pretzel/)
  gcc -O2 -o bfacf /home/user/-K-NOT_THEORY/research/code/bfacf.c
  python3 build_pretzels.py          # build links, component/crossing/Alexander check
  python3 make_seeds.py              # seeds.py:link_to_word, checked by latticeknot.is_lattice_polygon -> seeds.tsv
  # stage 1: 15 knots x seeds 1..24, schedule CYCLES=100 N_HIGH=100000 N_LOW=60000 ZMAX=0.2 ZLOW=0.02, 4 parallel (xargs -P 4) -> runs/raw.tsv
  ./bfacf WORD SEED 100 100000 60000 0.2 0.02
  # stage 2: restart from each knot's best stage-1 word with seeds 101..124 -> runs/raw2.tsv (jobs2.tsv)
  python3 verify.py                  # closure, self-avoidance, length, Alexander, SnapPy volume -> results.csv
